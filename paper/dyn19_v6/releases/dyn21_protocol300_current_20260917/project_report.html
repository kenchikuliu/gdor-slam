01 / EXECUTIVE SUMMARY

验收结论

这不是只有论文表格的展示包。当前 release 同时保留可执行源码引用、冻结计划、运行日志、轨迹、逐帧指标、Gaussian 地图、相机参数、真实渲染、比较表、HTML 和哈希清单。

01实验执行完整

4 个冻结 run cell 全部完成，每个 cell 处理并跟踪 300 帧，结果目录不复用历史输出。

02Tracking 明显改善

DYN-19 Full 在本地 Protocol-300 的平均 ATE 为 3.832 cm，优于 semantic 的 5.637 cm。

03Mapping 有明确边界

平均 SSIM 最高，但 PSNR 低于 Photo-SLAM 与 semantic；因此只报告 full-frame diagnostic。

04发布链可反查

源码 commit、计划、原始运行和 comparison 均进入 GitHub release，并由两套 SHA-256 清单覆盖。

当前可以支持的主结论

DYN-19 Full 在冻结的四序列 Protocol-300 本地包上提高了 tracking 稳定性，并在 mapping SSIM 上保持竞争力；结果、图像和运行制品均能回溯到固定源码与冻结计划。该证据不等价于跨论文统一协议下的全局 SOTA，也不将 full-frame PSNR/SSIM解释为静态地图的无条件优越性。
